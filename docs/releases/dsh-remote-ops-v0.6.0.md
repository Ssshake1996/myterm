# dsh-remote-ops v0.6.0

本次分两阶段更新全部工作区的样式与交互：统一控件、字号、间距和深浅色层次，再调整终端工具、网页辅助视图和文件选择操作。插件仍打开 DSH 原生右侧栏，保留主对话和草稿。

## 界面与交互

- 顶部使用工作区标签；版本、更新、诊断和“界面密度”移至“更多设置”。舒适 / 紧凑密度保存在当前浏览器。
- 终端目标与工具集中在同一栏，多个终端才显示会话条。搜索、快捷命令、独立命令及后台结果恢复继续可用。
- 网页优先展示地址和实时画面。“网页设置”收纳引擎、运行时安装、收藏和流程；“操作记录”按需打开；视口选项收进底部“画面设置”。返回网页保留地址草稿及当前页面。
- 切换已打开网页的显示方式时先确认；取消不派发操作，确认后重载网页并可能丢失未提交表单。切换请求执行期间禁用重复确认与取消。
- 文件操作随选择出现，上传按钮样式统一，浏览器上传显示字节进度。模块切换保留选择和草稿，不取消后台任务；目录刷新继续合并。
- 环境、快捷命令、弹层和诊断采用一致的表单与列表样式，保留键盘导航与焦点恢复。

## 安装与边界

只发布 `dsh-remote-ops-v0.6.0.tgz` 和 `SHA256SUMS-dsh-remote-ops-v0.6.0.txt`。Chromium 按需联网安装；独立窗口继续跟随 DSH 主机的 Windows 默认浏览器设置。不发布新的 Windows ZIP，不修改 Agent 或 DSH 内核。

```powershell
dsh plugin --profile web add .\dsh-remote-ops-v0.6.0.tgz
dsh web
```

升级前退出旧 DSH，安装后重新启动并刷新网页，在 Remote Ops“更多设置”核对 `v0.6.0`。环境、网站、快捷命令及浏览器偏好保留；运行中的终端和任务不能跨 DSH 进程重启恢复。

人和 Agent 共享网页与终端，使用 DSH 原生停止对话功能；不增加接管、暂停、停止按钮。SSH 参数空格问题仍不在本次范围。

321 项测试及 smoke、13 个浏览器场景、12 组真实 DSH 候选包验收通过。选中文字对比度为浅色 4.93:1 / 深色 8.55:1，主按钮文字为 5.41:1。正式包安装结果与限制见 [v0.6.0 验收记录](https://github.com/Ssshake1996/myterm/blob/main/docs/testing/dsh-remote-ops-v0.6.0-acceptance.md)。另一台电脑、真实远端 SSH/SFTP 和业务内网站点未在本轮实测。
