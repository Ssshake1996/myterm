# myterm v0.12.0

发布日期：2026-09-11

v0.12.0 是 Agent 工作区架构版本。myterm 将 Agent 界面切换为官方 DeepSeek Harness Web profile，并保留终端作为主要操作工作区。

## 官方 Harness 工作区

- 安装包携带锁定版本的官方 `@deepseek-ai/dsh` Web runtime（`0.1.5-rc.2`），由 Tauri 按需启动。
- Agent 面板使用独立顶层 Webview 加载官方 UI，默认收起；不在 React 中复制项目、对话、Goal、权限和工具组件。
- 启动器会复制官方包作用域并重建生成的 `profiles/web` 投影，避免 Windows 中断启动留下失效链接导致启动失败。

## SSH 环境绑定与协同

- 每个 Harness Conversation 可绑定多个已保存 SSH 环境、选择主目标或随时解绑。
- Host MCP 后端在每次远程工具调用时重新校验绑定，未绑定或目标不明确会返回结构化错误。
- Agent 自动建立的 SSH 连接保持 15 分钟空闲租约；用户主动打开的连接不会被自动关闭，应用退出时只回收 Agent 自己建立的连接。
- 保留 SSH、CLI、SFTP、文件、外部 MCP 和多 SSH 协同能力，工具调用统一经过 Host MCP。
