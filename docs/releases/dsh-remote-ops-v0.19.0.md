# dsh-remote-ops v0.19.0

嵌入网页统一跟随右侧栏的可用宽高，像调整 Chrome 窗口一样重新排版。页面保持原字号，超宽内容在网页内横向滚动，长页面纵向滚动。

- 移除视口、缩放和网站最低宽度等调整入口，设置仅保留引擎与运行状态。
- 调整侧栏不刷新网页，保留登录状态、页面及未提交表单；独立窗口继续使用自身窗口尺寸。
- 新打开的嵌入浏览器显示 Chromium 原生滚动条。热更新保留旧浏览器进程；如果旧进程仍隐藏滚动条，可先用滚轮操作，保存内容后关闭并重开该浏览器即可更新启动参数。
- 冷启动和热更新均迁移旧设置，旧宽度缓存不再参与计算，避免旧会话缺少自动适配字段时发生尺寸同步错误。
- 尺寸变化会使旧观察失效；Agent 重新观察后使用最新引用或坐标。正在执行的单次动作完成后应用最新尺寸。
- 尺寸同步失败保留请求地址、HTTP 状态和错误详情；错误显示不挤占网页高度，同一尺寸不反复重试，可点击重试恢复。
- 同步中英文 README、网页说明、MCP 说明及浏览器与录制随包 skill。不修改 Agent。

仅发布 tgz 和 SHA256 校验文件。验证使用隔离测试网站与 DSH 配置；不自动升级日常 DSH 实例。
