# dsh-remote-ops v0.20.1

修复网页定位检查后蓝色遮罩持续残留的问题。

- 定位检查使用透明背景的短暂边框，最多保留 1.5 秒，不再给整页染蓝。
- 当前对话正常结束、停止、异常或被销毁时，自动清除该对话的定位提示；网页、登录状态和表单保留。
- 提示期间用户仍可点击、输入和滚动。导航、关闭页面和流程结束会清理提示，旧计时器不会误清新提示。
- 同步中英文 README、网页使用说明和随包 browser skill，不修改 Agent。

仅发布 tgz 和 SHA256 校验文件。
