# myterm v0.9.8

## 交互终端与 Agent CLI

- 前端把 xterm 当前可见屏幕、光标行和光标前内容轻量同步给 Agent 会话；不引入第二套终端模拟器。
- `terminal_context` 返回最新屏幕证据，`terminal_send` 默认按完整目标命令计算并只发送缺失后缀。
- 当前光标行与目标命令冲突时，工具不写入任何内容，并返回当前行和目标命令；交互确认、分页和控制输入可显式使用 `raw` 模式。
- 更新 dsh-codex-agent 系统 Prompt 和工具 Schema，要求写入前读取终端现场。

## 桌面可用性

- SSH 连接失败详情支持直接选择和一键复制，重新连接改为独立操作。
- MCP 测试成功后可展开完整工具名称、说明、Transport 和 Input Schema，并复制 JSON 结果。
- 界面缩放从原来的最高 130% 扩展到 150%、175% 和 200%，终端字号继续独立控制。
- Agent 标题栏新增“新对话”按钮；任务运行时禁用，历史记录不被删除。
- 任务历史增加独立边框、背景和阴影，避免弹层与执行时间线融为一体。

## 方案取舍

- 优点：直接复用 xterm 的真实显示和光标状态，能适配会自动回显/补齐的设备 CLI，同时保持后端内核轻量。
- 代价：只有可见 xterm 会话具备屏幕快照；后台 Agent 创建且没有前端终端的 SSH 会话没有人工输入竞争，因此回退为完整命令发送。
- 安全边界：不自动清空不相容的现场输入，也不通过猜测覆盖用户已输入内容；冲突必须重新读取后再决定。

## 验证

- 前端 54 项测试通过，覆盖 xterm 屏幕同步、SSH 错误复制、MCP 工具详情和新对话。
- Biome Lint、TypeScript/Vite 生产构建、Rust 格式检查和单线程 `cargo check` 通过。
- Release 安装包、便携包、SHA-256 和 35 秒内存/句柄采样由标准发布脚本生成并校验。
