# dsh-remote-ops v0.16.2

将顶部导航收为两行，并修复终端绿色背景、蓝色文字等低对比组合的可读性。

- 终端、网页、桌面、文件、API 与设置同栏，设置固定右侧；移除插件内部重复的产品标题与当前终端名称。
- “环境”使用独立带边框按钮，放在终端标签左侧，不随标签滚动。其他模块在连接区域保留环境入口；抽屉左上角“返回”与 Esc 保留原内容并恢复入口焦点。
- 蓝色命令、青绿色目录，配色跟随深浅主题。设置 → 终端新增默认开启的“文字对比度保护”，处理 ANSI 16 色、256 色、真彩色及默认前景／背景组合，低对比文字调整至至少 4.5:1。保留程序背景，可关闭以查看原始 ANSI 颜色。
- 只调整显示，命令输入、工具返回、复制、搜索和日志文本不变。启动仍只打开一个默认本地终端；会话标签滚动、日志导出、后台连接沿用现有逻辑。
- 同步中英文 README、网页指南和随包环境管理／日志 skill，不修改 Agent。

安装包包含匹配的 Windows x64 与 Linux x64 随包浏览器。

仅发布 `dsh-remote-ops-v0.16.2.tgz` 和 `SHA256SUMS-dsh-remote-ops-v0.16.2.txt`。

验证范围与证据见[验收记录](https://github.com/Ssshake1996/myterm/blob/main/docs/testing/dsh-remote-ops-v0.16.2-acceptance.md)。
