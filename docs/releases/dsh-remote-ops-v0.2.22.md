# dsh-remote-ops v0.2.22

## 变更

- 终端输出下方提供整按钮直接下发，不经过 Agent；复用现有命令库，支持名称、多行命令、分组、搜索、排序和增删改查。
- 新增“显示为快捷按钮”和“执行前确认”。隐藏按钮保留命令；删除需确认；管理、编辑及取消预览不写终端。
- 常用命令窗格默认展开，上边界可上下拖动或键盘调整，双击恢复 190px；按插件实际高度约束，不限两行或 360px，内部滚动并记住高度和展开状态。
- 下发固定当前 owner、具体连接、输出流及命令版本，不自动连接或换目标；一次写入完整文本与 Enter，等待期间禁用重复点击。Agent 活动输入、未提交的本浏览器输入及失效目标会明确拒绝。
- 同请求回执在当前宿主进程中保留十分钟，最多 1024 条，不自动重试未知写入。“已写入终端”不代表命令完成；错误保留原始错误码、阶段和堆栈。
- 修复快捷按钮显示复选框保存时短暂跳回，以及分组改名后旧编辑器可覆盖新分组的问题。

没有新增运行依赖、第二套命令数据库、模型循环、跨浏览器输入权或连接编号/备注。原 Agent 工具契约和最多三条 SSH 连接的边界不变。

## 自动化

先新增回归并确认失败，再实现。`npm run check` 包含语法检查、56 项后端/传输/路由/独立命令测试、27 项生产客户端测试、7 项契约测试及烟测。

覆盖命令元数据持久化、精确文本、版本冲突、分组改名、完整一次写入、并发请求去重、EPIPE 未知回执、owner/流/Agent 拒绝、本地未绑定 Agent 的 HTTP 下发，以及真实组件点击/确认/管理和高度逻辑。

## 本机 3080 验收

- 真实 CMD 中文、多空格、多行回显；双击仅一个请求；本浏览器半条输入阻止下发，Ctrl+C 后恢复；编辑、隐藏/恢复、确认、排序、放弃修改和删除已验证。
- 36 条临时命令：190px 拖到约 556px，收起/展开、SFTP 往返、刷新保持高度。390px 窄屏保留 100px 输出区，没有水平溢出；截图已检查。
- 240 行输出后向上阅读，调整窗格及 SFTP 往返保持 scrollTop=8581.6；末行及提示符可见。
- 点击至写入回执的一次本机样本为 63ms，HTTP 样本约 2.4ms；不是远程命令完成耗时，也不是跨电脑或模型延迟承诺。
- 真实 SSH `笔记本` 的具体连接 `pty-2` 输出 `QUICK022-SSH  中文`，本地 CMD 游标未变化。重复请求返回原回执，旧流请求返回 HTTP 400 / `TERMINAL_STREAM_CHANGED` / `quick.dispatch`。连接已释放；SFTP `/tmp` 读取到 34 个条目。
- 宿主启动仅有 SQLite ExperimentalWarning。测试中预期的旧流 HTTP 400 不是未捕获页面异常；主流程未捕获页面异常为零。

本轮未重新验证真实模型调用、物理双客户端、操作系统输入法候选提交、文件传输字节一致性或 top/vim。不能推断所有交互程序是否正在等待输入，也没有恢复跨浏览器输入锁。3080 只作为开发验收环境，不代表其他电脑状态。
