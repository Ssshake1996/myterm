# myterm v0.11.4

发布日期：2026-09-02

本版本修复部分 OpenAI-compatible 网关返回不完整 SSE 结束事件时，模型测试成功但 DeepSeek Harness Agent 报 `HARNESS_ALL_ROUTES_FAILED`、ACP `-32603` 和 `SSE stream ended without [DONE]` 的问题。

## SSE 结束事件兼容

- 原逻辑只检查响应尾部是否包含 `[DONE]` 字符串，无法判断它是否是完整的 SSE 事件。
- 当网关以 `data: [DONE]` 或仅一个换行结束时，轻量模型测试按行解析能够通过，但官方 Harness Provider 的 EventSource 解析器不会产生结束事件。
- 新逻辑只接受带完整空行分隔的 `data: [DONE]` 事件；缺失、不完整或格式不标准时追加标准结束事件。
- 修复保持流式转发，不缓存完整模型响应，也不改变正常网关的响应内容。
- 发生兼容修复时，Harness stderr 会记录 `missing_done_event` 或 `incomplete_done_event`，便于后续定位网关行为。

## 回归验证

- 使用官方 Provider 同款 `EventSourceParserStream` 验证标准 LF、标准 CRLF、跨网络分块、缺少最终空行、缺失结束事件和正文包含 `[DONE]` 六种场景。
- 标准 SSE 不进行修改；非标准结束流补偿后均能产生且只消费一个有效 `[DONE]` 事件。
- DeepSeek Harness profile 检查、SSE 回归测试和 ACP 冒烟测试纳入统一运行时验证命令。
