# dsh-remote-ops v0.15.11

插件内网页默认以原始大小显示。宽度和高度独立跟随面板。固定宽度的网页超出面板时，拖动画面底部的横向滚动条即可点击右侧控件。需要查看全宽时，在 **设置 → 网页 → 网页画面缩放** 选择 **适应画面**。

有些系统会在登录页首次加载时根据屏宽隐藏菜单。先进入 **设置 → 网页**，填写网站地址与最低宽度（例如 `1280`），点击 **保存网站宽度**，再打开网址。同一协议、主机和端口的其他路径也会使用这个宽度。清空数值并保存即可恢复自动检测。
