# dsh-remote-ops v0.2.11

## 本次更新

- 修复部分电脑打开插件后本地终端输入无响应的问题：本地 CMD 进入 `running` 后输入层保持可写，并主动聚焦隐藏输入捕获层；本地终端不再依赖 Harness Agent 绑定。
- 本地 CMD 尚未启动时显示准确的等待状态，不再误导为等待 DSH Agent 初始化。
- 放大终端顶部的中断、环境、检查更新和刷新按钮，增加更清晰的交互状态。
- 环境按钮改为可重复切换：打开环境抽屉后再次点击可以收回。
- 环境抽屉关闭按钮改为明确的红色危险操作样式，并增加无障碍名称和悬停提示。

## 验证

- `npm run check`：通过。
- 客户端行为回归：通过，覆盖本地终端未绑定 Harness Agent 时仍可输入和启动阶段只读状态。
- 契约回归：通过，覆盖输入聚焦、环境抽屉 toggle、顶部操作按钮样式和红色关闭按钮。
- 本机 DSH Web `3080` 端口：端口由 DSH Web 进程监听，但当前验收浏览器未持有登录态，请求返回 `401 Unauthorized`，未完成真实页面交互验收。
- 未使用真实 SSH、SFTP 或模型成功作为自动化测试证据。
