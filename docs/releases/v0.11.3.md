# myterm v0.11.3

发布日期：2026-09-02

本版本删除 myterm 自有 Agent 权限策略，让 DeepSeek Harness 统一负责沙箱、批准和工具执行生命周期；同时重做 Agent 信息层级、模型测试诊断和 MCP 停用行为。当前仍处于开发阶段，不保留旧 Agent 数据结构的兼容路径。

## Harness 原生权限与 Agent 界面

- 删除旧的只读、用户确认、任务授权模式和 Rust `policy` 模块，不再由 myterm 对工具做第二次授权判断。
- 使用 Harness 的 `workspace-write` 与 `danger-full-access` 权限预设，访问入口移动到输入框下方。
- Host MCP 通过 Harness `tools/pre-execute` 生命周期接入权限预设；工作区访问模式请求 Harness 批准，完全访问模式直接执行。
- 删除 Agent 顶部 Session、Goal、Checkpoint、Compaction 等状态条，保留任务步骤、工具参数、执行结果、批准请求和最终答复。
- 保持 myterm 原有三套主题、SSH 终端布局和紧凑工作区结构。

## MCP 与模型诊断

- 关闭 MCP 服务器时立即清除已有连接池实例，避免已停用服务器继续调用并产生 `MCP_HTTP_INIT_FAILED`。
- “测试模型”使用与 Harness Agent 一致的 Chat Completions 流式契约，验证 SSE 数据、模型内容和 `[DONE]` 结束标记。
- DeepSeek 推理强度关闭时不再发送额外 thinking 字段，减少私有网关因扩展字段产生 HTTP 400 的风险。
- Provider 请求失败时记录准确请求阶段、HTTP 状态、响应类型、脱敏后的原始响应正文和堆栈，不再用笼统错误覆盖上游信息。
- 删除独立 session-title 模型请求，避免一次用户任务产生不必要的额外短请求。

## 数据切割与升级

- Agent 数据库 schema 升级到 v10；发现旧结构或损坏结构时删除旧 Agent 数据库及 WAL/SHM 文件并重新创建。
- 旧 Agent 权限、循环和插件配置不迁移，配置文件只写入当前 Harness 访问预设、Skill、MCP 与 Hook 字段。
- Agent 对话与任务历史会因数据库重建而清除。
- SSH 服务器、环境分组、快捷命令、主题、终端设置、Skill、MCP 配置和系统凭据不受 Agent 数据库重建影响。

## 验证

- Rust 单元测试、前端测试、TypeScript 类型检查、Biome 静态检查和前端生产构建通过。
- DeepSeek Harness profile 检查与 ACP 冒烟测试通过，并验证两种权限预设对 Host MCP 的实际执行决策。
- Release 构建继续携带固定 Harness runtime 和私有 Node，最终用户无需安装 Node.js。
