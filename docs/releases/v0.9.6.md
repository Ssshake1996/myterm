# myterm v0.9.6

发布日期：2026-08-27

## 本版更新

- 在 Agent 内核增加 `ensure_connected`：可复用已有连接，也可从保存的 profile 自动启动 SSH，连接过程和失败诊断进入统一会话事件流。
- 增加内置 `multi-ssh-coordinator` workflow plugin，使用 `session_catalog`、`session_connect` 和显式 `session_id` 实现多个 SSH 目标的串行协同。
- 多 SSH 协同默认先完成并验证目标 A，再操作目标 B；不会依赖 UI 当前焦点，也不会让插件绕过权限、审批、取消、超时或审计。
- Agent 时间线显示自动连接中的目标服务器、连接完成状态、插件标识和目标摘要。
- 增加标准 Windows 构建/发布脚本和完整操作说明，固定单线程前端测试与 Rust Release 构建，发布前执行运行时内存采样。
