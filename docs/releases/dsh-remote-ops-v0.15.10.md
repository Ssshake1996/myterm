# dsh-remote-ops v0.15.10

在 DSH 中告诉 Agent「在 myterm 后台检查设备的端口状态，录下操作，完成后告诉我」。后台模式使用插件管理的内置浏览器。你可以收起侧栏或继续编辑另一个网页标签。Agent 能复用该设备在插件中的登录状态、跟随弹窗并验证结果。需要查看过程时，在网页面板打开录制记录。

「跟随面板」会让响应式网页随侧栏重新排版，并按实际可用宽高等比缩放定宽设备页面。拖动分隔线时会保留当前页面和表单。

在 DSH 的「插件 → 添加插件 → 安装第三方插件」选择 `dsh-remote-ops-v0.15.10.tgz`。重启 DSH 后，可在 Remote Ops 的「设置 → 更新」核对当前运行版本。
