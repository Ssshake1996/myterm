# myterm v0.11.2

发布日期：2026-09-01

本版本把 Harness 模型层收敛到官方 DeepSeek Provider，并按 Harness 的实际生命周期与工具边界重做 AI 设置和 Agent 状态展示。SSH、CLI、SFTP、多 SSH、Skill 和 MCP 仍由原有安全边界提供。

## 原生 DeepSeek Provider

- Harness profile 使用官方 `@deepseek-ai/dsh-llm-deepseek`，ACP 固定选择 `deepseek-official` 路由。
- Rust 宿主只注入凭据环境变量、精确 Base URL、推理强度和模型列表；模型协议、流式响应、重试与错误由官方 Provider 负责。
- API Key 固定使用 Bearer 认证，删除旧的认证模式和兼容 Provider 配置分支。
- 支持主模型、备用模型和跨已保存 DeepSeek 服务的失败切换；删除主模型后会自动提升第一个有效模型。

## AI 设置与 Agent 界面

- AI 设置提供 DeepSeek 官方和 DeepSeek 网关预设，并增加 `off`、`low`、`high`、`max` 推理强度。
- “获取模型”与“测试模型”继续独立工作；JSON 预览展示 schema v6 和实际 Harness runtime/provider/route。
- Agent 顶部新增紧凑能力状态条，直接展示 Session、Goal、Checkpoint、Compaction、Skill 和 Host MCP。
- 删除旧 Core 循环步数、人工上下文参数和独立聊天传输相关界面与 IPC。

## 配置与升级

- AI 配置 schema 升级到 v6。当前处于开发阶段，旧兼容 Provider 的 AI 服务不迁移；升级后需要重新保存 DeepSeek 服务。
- 服务器、环境分组、快捷命令、Skill、MCP、对话历史和系统凭据不受本次 AI 配置重置影响。
- Base URL 不再自动补充 `/v1`；官方服务可使用 `https://api.deepseek.com`，私有网关需要填写完整 API 前缀。

## 构建与维护

- Harness 运行时检查覆盖官方包版本、必要插件/工具包、固定 ACP 路由和配置注入。
- 发行门禁保持通用：前端测试与构建、Harness check/smoke、Rust 格式/检查/测试、安装资源、包体、启动内存和 SHA256。
- 构建继续携带私有 Node 与固定 lockfile，最终用户无需安装 Node.js。
