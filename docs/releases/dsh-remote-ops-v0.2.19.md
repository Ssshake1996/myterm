# dsh-remote-ops v0.2.19

## 改进

- 环境默认进入/复用已有连接，多连接选择，独立新建和逐个释放；保留每个 owner/环境最多 3 个连接。支持通过宿主恢复已有会话，无需先向模型发消息。
- 人工/Agent 输入权协调，人工接管、交还、停止等待、Ctrl+C 和释放连接职责分开；不新增 Agent Loop 或权限系统。
- SFTP 双侧独立位置选择，多选文件/目录，宿主中转 SSH 互传，浏览器上传/下载，流式传输、进度、取消和显式冲突策略。
- 快捷命令多行表单、目标选择、填入/执行预览和多行粘贴确认；终端搜索、复制、字号/换行/快捷区高度持久化，中文宽字符光标修正。
- 可恢复的错误入口，保留原始阶段/代码/cause；白名单诊断预览导出。不增加运行时依赖。

## 验证

- `npm run check` 通过：38 项单元/传输/路由测试、15 项客户端行为、7 项契约和烟测。新增功能先补回归，修复过程中的失败测试保留。
- 本机 DSH `0.1.5-rc.1` 的 3080 开发验收：真实 SSH 登录和中文/空格回显、复用、3 连接上限、指定连接释放；终端、环境抽屉、快捷区、SFTP 和诊断切换。
- 真实模型：人工持有输入权时 `remote_terminal_send` 返回 `TERMINAL_MANUAL_CONTROL`，没有写入。交还后一次发送 `echo AGENT019-OK`，工具返回新输出游标 324→405；续读从 405 返回空串且偏移不变。核对了展开的工具参数/结果与 UI，不以模型总结替代证据。
- 真实 SFTP：浏览器上传 3,145,751 字节，宿主流式复制到同一 SSH 环境另一目录，下载逐字节一致。自动化另覆盖目录结构、冲突、取消、排队取消和暂存清理；不把这些模拟测试冒充真实网络验收。
- 真实宿主曾出现下载阶段 `HTTP 400`、空响应：streaming 请求桥对 GET 附加 body。上传 POST 与下载 GET 已分开注册，下载响应继续流式；新增方法/body 模式回归。
- 390px 窄屏与桌面截图、快捷命令多行回显、预览取消不写入、搜索和字号设置已验收。样本不代表性能或 token 降幅基准。

## 边界

- 未验证另一台客户端/真实 OS 输入法候选提交、两台不同 SSH 主机间的实际互传；直接输入中文文本不等于 IME 验收。
- PTY 静默不代表命令完成，仍返回 `completion: unknown`；未引入 shell 注入标记或完整终端仿真依赖。Sidebar 外层宽度由宿主维护。
- 文件传输不跨进程恢复、不回滚已完成文件；符号链接不跟随，远端覆盖要求原子 rename 扩展。任务并发 2、排队/运行合计 20、目录深度 32/条目 10,000。
- 3080 仅是开发验收环境，不代表用户另一台电脑的生产状态。未做旧版本数据迁移。
