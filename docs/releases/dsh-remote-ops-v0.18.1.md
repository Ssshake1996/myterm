# dsh-remote-ops v0.18.1

完善嵌入网页在“原始大小”下的滚动，支持保存桌面视口宽高，处理小面板和固定布局网页的可达性问题。

- 原始大小的两种视口模式统一双向滚动；滚轮先移动超出面板的画面，到边缘后滚动网页。
- 操作位置跟随尽量完整展示目标控件；目标大于面板时居中显示，避免只显示按钮中心而裁掉边缘。
- 网页滚轮带上当前鼠标的 CSS 坐标，先定位再滚动，支持内部滚动容器，避免沿用上次点击的位置。
- 设置 → 网页 → 原始大小 → 桌面视口，可独立保存宽、高，例如 1280×1600；不刷新文档，重启后保留。已有原始大小偏好不被重置，自动适配仍为默认。
- 有效观察或动作执行期间延后视口变化；坐标和录制保持浏览器 CSS 像素。
- 同步 README、使用说明、浏览器与网页录制随包 skill。

排查发现旧版基础样式已有 `overflow:auto`，不能仅凭 `data-panel-scroll=false` 断言完全没有滚动条。实际改进的是滚轮对外层纵向画面的处理、网页滚动目标定位，以及此前固定为 1024×768 的桌面尺寸。普通长页面可正常自动滚入视野；网站使用 `overflow:clip` 等限制裁掉的内容，需要调整视口或网站布局，本版不会改写网站样式或强制点击。

仅发布 tgz 和 SHA256，不修改 Agent。真实业务站点未提供，验收使用隔离测试页面；不自动升级日常 DSH 实例。
