# dsh-remote-ops v0.12.2

环境较多时更容易查找和管理，终端标签溢出时也能直接回到前面的连接。

- **统一环境管理**：SSH / API 使用分组导航、搜索和环境列表；窄栏自动切换为分组下拉框。SSH 的“进入 / 编辑 / 测试”和 API 的“使用 / 编辑”直接可见，删除及新建独立 SSH 连接收纳到行尾“更多”。
- **批量管理**：按需显示选择框，删除前列出本次选择的名称、地址和影响。取消不修改配置，重复点击不会重复执行，部分失败会保留对应选择并显示原因。SSH 分组菜单支持重命名及删除空分组；API 分组继续在编辑环境时设置。
- **保留操作上下文**：编辑取消保留搜索与分组，“返回工作区”保留原有终端、网页和 API 草稿。更多菜单支持键盘展开、Esc 关闭和焦点返回。
- **终端标签左右滚动**：标签溢出时显示左右箭头，到达边界置灰；可直接滚到早先打开的标签，无需关闭新连接。后台输出和状态刷新不抢走手动滚动位置；关闭或切换标签后保持选中标签可见。
- 同步中英文 README 与随包环境 / API 管理 skill，更新安装及内网更新清单示例。未修改 Agent。

验证：444 项自动化检查与 smoke、24 个浏览器场景（106 个步骤）通过；Windows 11 / DSH 0.2.0-rc.2 / Chrome 中安装候选包后，终端与环境管理 13 项验收通过。SSH 使用隔离的本地测试服务，未连接用户的生产设备。详见 [v0.12.2 验收记录](https://github.com/Ssshake1996/myterm/blob/main/docs/testing/dsh-remote-ops-v0.12.2-acceptance.md)。

发布资产仅包含 `dsh-remote-ops-v0.12.2.tgz` 与 `SHA256SUMS-dsh-remote-ops-v0.12.2.txt`。已有用户可在“设置 → 更新”检查并更新；内网更新源请上传这两个文件，并运行随包脚本生成对应的 `latest.json`。
