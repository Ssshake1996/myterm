# myterm v0.12.1

发布日期：2026-09-11

## DSH 启动修复

- 为 Tauri 启用官方顶层 WebView API 所需的 `unstable` feature，修复 Agent 面板启动时报 `DSH_WEBVIEW_CREATE_FAILED` 的问题。
- WebView label 按 myterm 进程生成唯一值，避免与其他 myterm 窗口或独立 Harness WebView 混淆。
- Agent 面板在应用首次打开时自动启动；用户仍可手动收起，后续展开复用同一个 DSH 进程和 WebView。
- Node/DSH 子进程在 Windows 使用 `CREATE_NO_WINDOW` 启动，不弹出 CMD 窗口。

## DSH 运行隔离

- 内嵌 Harness 使用独立的 myterm `DSH_HOME` 命名空间，不读取或修改电脑上独立 DSH 的 `~/.dsh`。
- 内嵌实例继续使用独立的随机 Host MCP 端口和 Bearer Token；双实例 ACP smoke 测试确认两个 Web profile 可同时启动并保持存活。
- 生成的 profile/runtime 仍与对话数据分离，启动失败时只重建可生成的 `profiles/web` 投影。

## 发布验证

- 前端类型检查、lint、单线程测试通过。
- Harness lock/profile 检查和双实例 smoke 测试通过。
- Rust fmt、check 和宿主测试通过。
- Release 分发包审计及内存采样通过。
