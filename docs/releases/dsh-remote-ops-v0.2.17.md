# dsh-remote-ops v0.2.17

## 本次更新

- 修复本地 CMD 发送后立即返回旧输出；发送等待新内容，Agent 的 read/signal 支持界面中的 `local-cmd`。
- 工具与 UI 使用同一输出流，默认返回 16 Ki 码元增量；通过 `nextOffset`、`streamId` 续读，支持长轮询和分页，不重复附带历史 viewport。
- 修复有效游标跨页跳过内容、同长度新流未重置缓存、readOutput 重复消费，以及取消/进程退出后等待未释放。
- 输入队列固定目标终端及 owner，避免切换期间串写；按环境发送复用唯一活动连接，多连接时要求明确 sessionId。
- 明确 `completion: "unknown"`：静默、超时或 running 不代表命令完成；工具返回原始终端流，不冒充渲染后的屏幕。
- 优化终端工具栏为较大图标控件，增加输出连接、Agent 绑定和等待状态；快捷命令默认收起。
- 修复 SFTP 返回时历史位置丢失、窗口缩放时底部跟随丢失；上移阅读不被新输出打断，可一键回到末尾。
- 不新增运行时依赖，不改变产品边界或引入旧数据迁移。

## 验证

- `npm run check`：通过；22 项单元、9 项客户端行为、7 项契约测试及烟测全部通过。
- 本机 DSH Web `3080` 候选包：Sidebar、240 行滚动、末行、SFTP 往返位置恢复、390px 窄屏及桌面缩放、环境开关、诊断切换、快捷命令回显、Ctrl+C、本地 CMD 退出重建通过。
- 真实模型调用 `remote_terminal_send/read`：发送得到新输出，续读空增量，界面显示相同标记；初次错误使用 sessionId 参数导致 `REMOTE_ENV_NOT_FOUND`，更正为 session 后成功。缺少目标现在返回明确的 `REMOTE_SESSION_REQUIRED`。
- 真实 SSH 回显、SFTP 本地和远端目录读取通过；临时 SSH 连接和快捷验收数据已释放/清理。
- 自动化回归使用 fake 宿主验证工具和路由契约，真实模型/网络证据来自上述独立验收。

## 已知边界

- 未验收另一台电脑、真实操作系统输入法候选提交和 SFTP 文件上传下载；不能把本机结果外推到所有 DSH 主机。
- 不提供任意交互命令的可靠退出码。Agent 绑定状态不是已读回执；不承诺模型必然理解输出或节省固定比例的时间/token。
