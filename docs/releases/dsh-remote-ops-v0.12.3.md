# dsh-remote-ops v0.12.3

修复 DSH 0.2.1 系列在安装插件时自动重载，导致更新卡在“正在安装”并伴随终端输出刷新 404 的问题。

- 安装前按需等待任务完成并保留运行状态，避免安装过程与插件卸载相互等待；安装后的版本切换仍等待后台任务结束。
- 更新提交立即返回受理结果，后台完成安装与热加载；状态恢复只查询进度，不会重复安装。切换工作区或客户端重载后继续查询。
- 重载期间的短暂接口中断自动恢复；持续失败显示请求地址、阶段和响应摘要。增加“刷新更新状态”，安装超过 10 分钟未返回时明确显示结果尚未确认。
- 保留对话与草稿、已有终端和网页连接、API 登录状态与记录；同步中英文 README 和随包更新 skill，不修改 Agent。

**从 v0.12.2 及更早版本首次迁移，请先结束任务，使用 DSH 自带插件管理或 CLI 安装本版 tgz。** CLI 安装后若运行版本仍旧且页面可操作，点击“重试应用已安装版本”即可只应用已安装的包；宿主不支持热加载时重启一次。如果旧更新流程已经卡住，核对安装日志和已安装版本，在安装完成后重启 DSH 一次，不要重复提交安装。新包无法修复已经执行中的旧版更新流程；本次迁移后可使用修复后的热加载。

验证范围与证据见 [v0.12.3 验收记录](https://github.com/Ssshake1996/myterm/blob/main/docs/testing/dsh-remote-ops-v0.12.3-acceptance.md)。隔离测试服务不代表用户生产设备。

发布资产仅包含 `dsh-remote-ops-v0.12.3.tgz` 与 `SHA256SUMS-dsh-remote-ops-v0.12.3.txt`。内网源先上传这两个文件，再使用随包脚本生成并发布 `latest.json`。
