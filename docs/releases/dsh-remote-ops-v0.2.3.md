# dsh-remote-ops v0.2.3

## 修复内容

- 移除插件按钮在右侧 Sidebar 不可用时自动启动新 DSH 会话的降级行为。插件会等待服务与 Tab 注册完成，最终显示具体失败原因。
- 修复跨电脑使用时难以判断 DSH profile、Sidebar 服务或插件 Tab 未就绪的问题。
- 重构终端与快捷命令区域为紧凑两行布局，快捷命令区按内容高度展示并限制内部滚动，消除无效大块留白。
- 新增独立 SSH 密码输入框；密码通过 Harness `credentials.set` 保存，环境 JSON 只保留凭据引用。
- 编辑已配置环境时，密码留空保留原凭据；输入新密码则更新同一凭据或指定的新引用。
- 校验 Harness 凭据引用必须符合 POSIX 环境变量命名规则。
- 终端继续使用 DSH 主题语义色，命令输入保持左对齐。

## 验证

- `npm run check`
- `npm pack`
- 本地 DSH Web 实际打开 Remote Ops、环境表单、快捷命令布局与启动失败提示验证
