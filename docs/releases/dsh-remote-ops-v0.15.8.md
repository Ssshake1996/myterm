# dsh-remote-ops v0.15.8

**拖动 DSH 右侧分隔线时，内嵌网页会跟随面板缩放。** 在「网页」中选择「适应画面」，按住分隔线向两侧拖动，画面会随可用空间变化，响应式网页也会在拖动过程中重新排版。调整窗口大小时同样生效。

**改善设备管理页面的显示。** 对于在子框架中打开的固定宽度表单，浏览器会按内容宽度调整视口；从表单返回响应式页面后，会恢复到当前面板宽度。

在 Remote Ops 的「设置 → 更新」中点击「检查并更新」。安装包内含 Windows x64 和 Linux x64 的内嵌 Chromium。GitHub 和内网 HTTP/HTTPS 更新源可使用同一份安装包与校验文件。[下载 v0.15.8 安装包](https://github.com/Ssshake1996/myterm/releases/download/dsh-remote-ops-v0.15.8/dsh-remote-ops-v0.15.8.tgz) · [SHA256 校验文件](https://github.com/Ssshake1996/myterm/releases/download/dsh-remote-ops-v0.15.8/SHA256SUMS-dsh-remote-ops-v0.15.8.txt)
