# dsh-remote-ops v0.20.0

GitHub Release 更新显示真实下载进度，并支持中断后继续下载。

- 显示已下载大小、百分比、速度和预计剩余时间；未知大小显示已下载字节，不伪造百分比。
- 下载边接收边落盘，断流或停滞后最多自动重试三次；失败后可继续下载，重启 DSH 后也可手动恢复。
- 锁定原下载版本，通过 Range、If-Range 和 ETag 验证续传；服务端忽略续传或文件变化时安全重下。
- 连接等待 30 秒、无数据等待 60 秒；持续下载不再受固定 10 分钟总时限影响，GitHub 限流遵守服务端等待时间。
- 完整 SHA256 和包身份校验通过后才安装；保留已有防重复安装、任务结束后热加载与连接保留逻辑。
- 同步中英文 README 与随包更新 skill，不修改 Agent。已有 HTTP/HTTPS 更新源流程保持原有行为。
