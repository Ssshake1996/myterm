# dsh-remote-ops v0.2.14

## 本次更新

- 修复环境已有 PTY 时再次连接触发 `DUPLICATE_NAME`：每个新连接使用独立 PTY name，环境 ID 仅作为会话归属。
- 同一 owner+环境最多 3 个连接，环境快照显示实际连接数；多个连接时要求使用明确 sessionId，并支持释放具体连接。
- 宿主 PTY 列表成为 running 状态事实来源，切换会话或重启 DSH 后不会继续显示已消失的连接。
- 批量命令复用单个环境连接，避免命令数量消耗连接额度。
- SFTP 改为占满插件主区的本地/远端双栏工作区，支持本地目录读取、单文件上传和下载。
- 新增会话上限、连接释放、状态回收、本地 SFTP 列表和 UI/路由契约回归测试。
