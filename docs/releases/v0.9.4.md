# myterm v0.9.4

发布日期：2026-08-26

## 本次更新

- 为 `dsh-codex-agent` 增加版本化系统 Prompt，固定证据优先、工具循环、长输出分页、目标会话、权限、Skill/MCP 边界和错误事实规则。
- AI Profile 的 System Prompt 改为附加指令，不再替换 Agent 核心系统规则。
- Agent 启动任务时注入运行时 MCP 能力目录说明；模型依据实际工具名称、描述和 JSON Schema 选择 MCP 工具，不再假设未注册能力。
- 多行快捷命令按行串行发送并等待终端提示符，防止不同 CLI 命令粘连；增加并发点击保护。
- 会话编辑表单先渲染，Shell 检测后台加载，避免打开新会话或编辑连接信息时卡顿。
- 修正高 DPI/字体缩放下终端鼠标选区偏移，并增加终端文本复制、粘贴、全选和清除选择右键菜单。

## 验证

- 前端测试：50 项通过。
- dsh-codex-agent 系统 Prompt/MCP 能力目录 Rust 测试通过。
- TypeScript 类型检查、Biome lint、前端生产构建和 Cargo 格式检查通过。
