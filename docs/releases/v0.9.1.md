# myterm v0.9.1

## 重点变化

- `dsh-codex-agent` 成为桌面端唯一内置 Agent，替换旧版 Rust 模型循环。
- Codex Core 统一负责 Thread/Turn 历史、工具调用循环、上下文压缩、Subagent Graph 和取消。
- myterm 保留 SSH/SFTP 工具、权限审批、Skill/MCP 装载、任务审计和前端事件投影。
- 旧 Agent 配置字段 `profile`、`bundles`、`enabled_plugins`、`max_steps` 不再持久化；打开旧配置时会自动清理，内部安全边界固定为 64 步。
- Agent 面板显示 dsh-codex-agent 标识、工具参数摘要、工具结果、压缩重试、Subagent 状态和原始错误详情。
- 保留原有 JSON 配置预览、AI 模型测试、Skill 发现、stdio MCP、权限模式和多 SSH 工具能力。
