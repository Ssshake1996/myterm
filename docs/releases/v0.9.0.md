# myterm v0.9.0

发布日期：2026-08-26

## 主要更新

- 新增独立发布的 DeepSeek Harness 原生插件 `dsh-codex-agent`。
- 通过同进程 N-API 集成裁剪后的 Codex Core，不启动 Sidecar 或 Codex app-server。
- Codex Core 独占 Agent Loop、Thread/Turn、自动压缩、Tool Call 顺序、多 Agent 和 Agent Graph。
- 支持内网 Chat Completions、流式文本、工具调用增量、多轮 Tool Result、usage 和原始错误详情。
- 支持 Root Agent 创建、并发运行、等待、超时和取消 Subagent，并持久化 Graph 状态与结果。
- 支持显式白名单的 Streamable HTTP MCP；禁止 stdio、本地 MCP Server、自动发现和通配符工具授权。
- 支持固定地址 Web Search，未配置时不会注册，并拒绝其他宿主插件绕过白名单提供同名工具。
- API Key 只允许通过环境变量或宿主 Secret 注入，不写入配置、Session、Thread、Graph 或审计记录。
- Chat Completions 使用 Rustls 并加载操作系统证书库，适配企业根证书和内网 CA。

## 压缩失败策略

压缩首次失败后最多重试 3 次，总计最多 4 次。退避时间为 100ms、250ms、500ms。只有严格摘要校验成功后才会在一个 SQLite 事务中提交 Thread、Graph revision 和审计记录。四次全部失败时终止当前 Turn，不继续普通模型请求，不截断原始历史，也不使用 fallback。

## 已知边界

- `dsh-codex-agent` 在本版本中作为独立 Harness 包发布，桌面端内置 Agent 不会自动切换到该运行时。
- 当前原生插件资产为 Windows x64 MSVC；Linux 与 macOS 需要各自构建。
- Web Search 使用固定 POST JSON 企业网关协议，不直接适配任意公网搜索 API。
- Skill 驱动 OS 安装和复杂长期任务编排仍属于后续版本。
