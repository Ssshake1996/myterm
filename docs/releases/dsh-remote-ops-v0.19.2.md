# dsh-remote-ops v0.19.2

嵌入网页的底部横向、右侧竖向滚动条使用更清晰的滑块和轨道配色，并支持按住滑块拖动。

- 浅色网页使用深灰滑块与浅灰轨道，网页声明深色主题时使用浅灰滑块与深色轨道。保留默认及网站自定义的滚动条尺寸、页面布局与 CSS 像素坐标。
- 支持按下、拖动、移出面板后松开及取消；合并待发送的移动事件，切换工作区或页面变化时释放按键状态，避免拖动后误点。
- 修复补充验收中发现的原生弹窗排队问题：人工点击触发确认框后，接受、取消及关闭网页不再等待被弹窗阻塞的输入；关闭最后一个网页会等待浏览器清理完成。
- 配色在刷新、新标签、跨域 iframe 与已打开页面的热加载后保持；继续跟随侧栏宽高，不增加显示模式。
- 同步 README、网页说明、浏览器和录制随包 skill。不修改 Agent。

仅发布 tgz 和 SHA256 校验文件。验证使用隔离 DSH 配置与测试网站，不自动升级日常 DSH 实例。

验证：540 项桌面、单元、客户端与契约检查和 smoke，11 项真实浏览器专项、5 项录制测试、26 个界面场景通过。相同最终包通过真实 DSH 的 16 项网页/录制、6 项 Agent/MCP 与 10 项热更新检查。
