# dsh-remote-ops v0.19.1

嵌入网页的底部横向、右侧竖向滚动条使用更清晰的滑块和轨道配色，并支持按住滑块拖动。

- 浅色网页使用深灰滑块与浅灰轨道；网页声明深色主题时自动切换为浅灰滑块与深色轨道。仅调整滚动条外观，保留原生及网站自定义滚动条尺寸、网页布局和 CSS 像素坐标。
- 补齐鼠标按下、移动、松开及取消。拖动移出面板后仍能释放；切换工作区、页面变化或请求失败时清理按键状态，避免拖动后误点。
- 合并尚未发送的移动事件，避免慢连接积压过期位置；普通点击、滚轮、键盘及 Agent 操作继续使用同一浏览器。
- 配色支持新页面、刷新、跨域 iframe 及已打开页面的热加载，无需重新登录或清空草稿。视口继续跟随侧栏，不增加显示模式。
- 同步中英文 README、网页与 MCP 说明、浏览器及操作录制随包 skill。不修改 Agent。

仅发布 tgz 和 SHA256 校验文件。验证使用隔离 DSH 配置与测试网站，不自动升级日常 DSH 实例。
