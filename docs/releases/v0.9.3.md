# myterm v0.9.3

发布日期：2026-08-26

## 本次更新

- Agent 权限模式统一为“只读 / 用户确认 / 完全授权”，完全授权不再对普通工具和 Hook 重复弹窗，硬拒绝规则仍然生效。
- 终端新增石墨青金、森林护眼、午夜高对比三套命令配色模板，命令输入与服务器回显分色显示。
- 快捷命令和 Agent 回填命令沿用当前终端配色。
- 修复 `cat` 或无结尾换行输出导致 shell 提示符与最后一行粘连的问题，并兼容 SSH 分段回显。
- 同步更新中文/英文 README、用户指南和 Agent 规范文档。

## 验证

- 前端测试：47 项通过。
- Rust 测试：48 项通过，1 项因系统凭据库环境跳过。
- TypeScript 类型检查、Biome lint、前端生产构建和 Rust 格式检查通过。
