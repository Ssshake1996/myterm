# dsh-remote-ops v0.9.1

终端标签与常用操作合并为一行；请求失败可直接定位接口或更新文件，后台同类刷新错误不再反复弹出。

- **紧凑终端栏**：桌面标签约 32px 高，搜索和当前 TXT 导出直接显示；全部日志 ZIP 在“更多”。路径移至底部状态栏，SSH 尺寸统一在“设置 → 终端”，常用命令保留在下方。
- **标签与尺寸反馈**：缩窄侧栏或使用方向键、Home/End 时，当前标签保持可见；SSH 尺寸在没有新终端输出时也能正确同步。
- **可定位的错误详情**：区分状态刷新、终端输出刷新与插件更新失败，展开查看方法、脱敏地址、HTTP 状态、阶段、时间和响应摘要；网络失败显示未收到响应。
- **更新分阶段定位**：分别标明版本清单、SHA256 文件和安装包的失败地址，区分更新源和插件接口的 HTTP 状态；失败详情可从更新状态恢复。
- **后台提示去重**：同一 DSH / 插件运行期间，同一后台刷新错误只自动提示一次。关闭、切页和刷新网页保留去重，后台仍会重试；手动刷新仍提供反馈，状态恢复清除对应错误，识别到后端重新启动后重新允许提示。
- README 与随包更新、日志 skill 同步操作路径及排障流程；不修改 Agent。

发布附件仅 `dsh-remote-ops-v0.9.1.tgz` 与 `SHA256SUMS-dsh-remote-ops-v0.9.1.txt`。内网通过随包脚本生成 `latest.json`，继续使用 HTTP/HTTPS 地址和手动检查更新。

发布前验证：388 项插件测试、20 个浏览器场景，以及真实 DSH 0.2.0-rc.2 的 7 组完整功能、8 组 HTTP 升级和故障验收通过。状态接口 404 使用受控故障注入；正常升级中未观察到该故障。

升级前完成运行中的任务并导出需要的日志；安装后完全重启 DSH、刷新网页，在“设置 → 通用”确认 v0.9.1。验证证据和范围见[验收记录](https://github.com/Ssshake1996/myterm/blob/main/docs/testing/dsh-remote-ops-v0.9.1-acceptance.md)。另一台电脑原始 404 的原因仍需以新详情中的实际失败地址确认。
