# myterm v0.11.0

发布日期：2026-08-29

这是 Agent 控制面的一个大版本。myterm 保留精简 Codex Core，不恢复完整 app-server；在其上增加持久 Goal、自动续跑、事件驱动后台任务、跨 Provider 路由和统一 MCP CapabilityProvider。用户仍然只需输入普通任务，不需要判断长短或使用 `/goal`。

## 自动 Goal 与长任务

- 每个普通输入自动创建或复用 Goal。Conversation 是对话边界，Turn 是内部执行段，Goal 才是完整任务的完成单位。
- Core 的 64 Step 边界改为 `continuation_required`：当前 Turn 保存 checkpoint 后自动让出并继续，不再显示 `maximum step count 64 was reached`。
- 默认 Goal 不设置隐藏 Token 总预算；循环保护改为关注重复调用和无进展状态。
- 支持 `active`、`paused`、`waiting_approval`、`waiting_external`、`blocked`、`completed`、`failed`、`canceled` 状态，以及暂停、恢复和取消。
- 目标、范围、结果或风险存在实质歧义时，Agent 先安全读取现场，再持久化准确问题等待用户；允许多轮澄清并继续同一 Goal。
- 运行中输入提供“立即调整”和“排队执行”，分别注入当前 Turn 或在当前 Turn 后继续。

## Job、恢复与会话生命周期

- 后台 Job、Evidence 和激活 Skill 改为 Goal 级，可跨 Turn 和应用重启恢复。
- Job 完成通过事件通知唤醒等待中的 Goal，删除固定轮询和任意等待超时。
- 重启只把被中断 Turn 标记失败，非终态 Goal 暂停等待恢复；退出时统一取消 Turn/Job/审批并释放 Runtime/MCP。
- 最多并发 4 个 Conversation；Runtime 缓存排除活动会话，避免长任务因空闲淘汰规则被清除。
- 删除历史对话时拒绝活动 Turn 或 Job，并递归清理 Root/Subagent Thread、审计索引和原始 artifact。

## 模型与上下文

- 每个主/分析/备用模型可引用另一份已保存 Provider 配置，实现跨 Base URL、认证和 Provider 的路由与回退。
- 删除仍被模型路由引用的 Provider 会返回明确错误；AI 设置测试使用稳定模型路由 ID。
- 瞬时请求最多 3 次总尝试，流式输出后不重放；连续 3 次终态瞬时错误会熔断 30 秒。
- 上下文窗口、Responses/Chat 协议和压缩阈值完全自适应，AI 设置不再显示人工 Token 控件。
- Checkpoint v2、Result Capsule 和原始结果分页保持无损；压缩仍为初次加 3 次重试，失败不截断历史。

## MCP、Skill 与多 SSH

- MCP 重构为统一 Transport 抽象，支持 stdio 和 streamable-http，并统一 Tools、Resources、Prompts、进度、Schema 校验和原始 Evidence。
- 连接池按配置指纹复用，目录缓存 5 分钟、空闲 30 分钟、上限 16；发现/read 操作可重连一次，工具调用失败不会自动重放副作用。
- 池化 MCP 客户端在调用完成、失败或超时后清理进度回调，避免事件泄漏到其他 Goal。
- Skill 支持常见 hyphenated 元数据与 YAML 列表，执行 platform、model-invocable、allowed-tools 和风险校验；正文按 Goal 恢复。
- 多 SSH 对同一 Session 的状态变更串行、不同 Session 可并发；`session_wait_until` 用一次有界只读调用表达 A 操作后观察 B 的条件。
- CLI 仍以完整目标命令结合 xterm 实时光标行计算缺失后缀，参数空格和终端编辑守卫保持原样。

## 前端与诊断

- Agent 面板增加 Goal 状态条、续跑次数、checkpoint、暂停/继续/取消、运行中输入模式和后台状态刷新。
- 对话历史可分页读取完整事件；活动 Conversation 禁止删除。
- AI 设置移除人工上下文参数，模型行支持选择 Provider；JSON 预览升级为 schema 5。
- `capability_progress`、`session_wait_progress` 和 Skill 恢复警告进入时间线，错误继续保留阶段、稳定代码、原始详情和堆栈。

## 升级说明

- Windows 安装器会替换旧版本并保留服务器、环境分组、快捷命令、AI/Agent、Skill、MCP 和系统凭据引用。
- AI 配置 schema 自动升级到 5；旧单 Provider 模型继续可用，新 Provider 引用为可选字段。
- 旧 Core 配置名 `maxSteps` 继续作为兼容别名，但桌面端不再把它暴露为整个任务的限制。
- 便携版请替换完整目录，不要只覆盖单个 EXE。
