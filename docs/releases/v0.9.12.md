# myterm v0.9.12

本版本修复 SSH 终端滚动与产品 CLI 输入编辑问题，并把受保护的终端行编辑能力纳入 dsh-codex-agent。

## 主要变化

- 终端右键菜单新增“自动换行”开关；关闭后启用横向滚动区域。
- 终端纵向滚动条保持可见，输出跟随底部时尊重用户手动上滚，最后一行可以正常滚动到。
- 完整 CLI 命令会清理实际控制字符、ANSI 转义序列及常见的 `\\003`、`\\033`、`\\u0003` 表示；控制字符连接参数时会补回必要空格，并返回 `cleanedControlCount`。
- raw 终端输入保持原样，Ctrl+C、分页键和 REPL 控制不受影响。
- 新增 `terminal_edit` 工具。Agent 必须先读取终端快照并提供精确的光标行保护，可执行退格、删除、光标移动、清行、替换当前输入和显式 Ctrl+C，避免盲目覆盖用户输入。
- 同步更新 Agent 权限策略、工具说明、用户手册和开发经验记录。

## 验证范围

- 前端 Vitest：59 项通过。
- Rust 单元测试：75 项通过，1 项系统凭据测试按环境忽略。
- TypeScript、Biome、Rust fmt/check 和生产构建通过。
- 本地浏览器验证了自动换行菜单、终端纵向滚动和横向溢出样式。
