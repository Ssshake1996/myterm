# dsh-remote-ops v0.2.9

## 本次更新

- 修复终端输出区域比父容器高 20px，导致最后一行和滚动条底部被裁剪的问题。
- 增加轻量 VT 屏幕模型，正确处理 Windows ConPTY 清屏、光标定位、回车覆盖和滚屏，不再显示初始化屏幕产生的大段空白。
- 终端正文从完整状态快照中拆分，改为绝对游标增量传输和长轮询；空闲时只保持一个等待请求。
- 输入按短窗口合并并串行发送，不再为每个输入批次重新获取完整状态。
- 优化自动跟随：用户向上查看历史时保持当前位置，重新滚到底部后恢复跟随。
- 优化 4MB 后端输出缓冲的字节统计和收缩算法，避免持续全量计算及反复字符串拼接。

## 验证

- `npm run check`：通过。
- 使用本机 DSH Web `3080` 端口验证初始 ConPTY 空屏快照不再产生可见空白。
- 连续输出 2000 行约 0.67 秒完成渲染，末尾提示符完整显示，滚动区域底部间隙为 0。
- 验证滚轮上移后新输出不抢占阅读位置，滚动到底部后自动跟随恢复。
- 14 秒空闲采样中，Host 私有内存、句柄和 CPU 计数均无增长。
