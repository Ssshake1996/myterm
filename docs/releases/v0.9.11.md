# myterm v0.9.11

本版本对 dsh-codex-agent 的对话上下文进行一次完整重构：用持久 Conversation/Turn 替代“每次发送新 thread”，并用 Provider Context Adapter 同时支持 Responses 增量续接和 Chat Completions 本地回退。终端长输出导航和产品 CLI 精确补全也一并收口。

## 主要变化

- 新增持久 Conversation 和 Turn 层级。只有点击“新对话”才创建新上下文；同一对话的用户纠正、工具事实、Evidence 和精确 CLI 命令可跨回合恢复。
- 对话历史改为按 Conversation 聚合，显示 Turn 数并恢复全部时间线；旧版本任务自动迁移为独立单回合对话。
- Turn 运行期间输入框保持可用，可用“追加要求”把新指令注入当前执行；有界 32 条 steering 队列防止无限堆积，停止仍为独立操作。
- AI 设置增加上下文协议：自动、Responses、本地上下文。Auto 优先 Responses `previous_response_id` 和服务端压缩，网关明确不支持时持久回退到 Chat checkpoint + tail。
- 每个模型可配置上下文窗口与压缩阈值。本地 checkpoint 改为严格版本化 JSON，保留目标、约束、用户纠正、原样命令、工具事实、Evidence 引用、未解决项和权限状态。
- Responses 和 Chat 运输都正确遵守 AI 配置的 Bearer Token 或原始 Authorization API Key 模式。
- 终端增加在白色、护眼色和深色主题下都可见的纵向滚动条。
- 产品 CLI 执行坚持由 Agent 给出完整目标命令，宿主根据 xterm 当前光标行只发送精确缺失后缀。`show`、`show ` 和 `show system` 分别补全为 ` system general`、`system general` 和 ` general`，前缀冲突时不发送。

## 升级说明

Windows 安装器会替换旧版本程序，保留服务器、快捷命令、AI/Agent 配置和操作系统凭据引用。Agent 数据库首次打开时自动迁移到 schema v5。便携版请解压到新目录或替换完整目录，不要只复制单个 EXE。

## 验证范围

- dsh-codex-core 单元与 HTTP 集成测试：跨 Turn 恢复、steering、Responses 增量输入、provider checkpoint、本地压缩重试和 CLI 空格保真。
- myterm Rust 测试：旧数据库迁移、Agent 状态、SSH/MCP/权限/错误契约和 CLI Executor 回归。
- 前端单线程测试、TypeScript、Biome 和 Vite 生产构建；主要 Agent 和 AI 设置流程进行真实界面回归。
- NSIS 安装器、便携 ZIP、分发审计、SHA256 与 35 秒运行时内存/句柄采样。

## 当前边界

- Responses 此版使用非流式 JSON 响应；Chat Completions 继续使用 SSE 流式文本。
- 不新增云端长期记忆、工作流 DAG、云端 Skill 市场或新常驻服务，继续保持轻量桌面内核。
