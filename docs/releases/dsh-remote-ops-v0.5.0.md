# dsh-remote-ops v0.5.0

## 工作区与样式

- 使用“终端 / 网页 / 文件”标签，环境管理在插件内独立展开，诊断、刷新和更新归入“更多设置”；保留宿主左侧入口、原生右栏、主对话和草稿。
- 合并样式注入，统一 DSH 主题 token、按钮、输入框、间距、图标和深浅主题；终端显示设置与技术状态折叠，环境和诊断不再盖住工作区内容。
- 工作区、终端选择和环境筛选按对话恢复；从网页进入环境后切回选中的终端。分组与确认弹层统一焦点、Tab、Esc 和返回入口。

## 交互与性能

- 嵌入网页支持跟随面板/桌面视口、标题标签和关闭当前页面；调整视口不重载页面，旧坐标失效，显示切换期间过期布局请求安全丢弃。显示模式切换前提示重载。
- 网页工作区首次读取状态时暂时禁用导航与显示切换，避免切回网页时误改偏好或重复打开浏览器；读取失败可就近重试。
- SFTP 增加筛选、全选、Shift 连续选择、Enter 打开目录、窄屏来源/目标切换、目标名称和折叠传输历史；保留跨模块上传与目录刷新合并。文件选择在重取目录后核对，历史目录数据不写入缓存。
- 修复进入文件夹时排队刷新导致地址栏停留旧路径的问题，并保留未提交的路径编辑。
- UI 独立命令与视图生命周期分离，关闭结果视图或刷新网页后可恢复任务/结果；按对话隔离，后端内存最多 32 项、完成后最多十分钟。列表只返回元数据，按需读取单个结果；重试同一请求不重复执行，未知结果不自动重跑。
- 普通 ASCII/SGR 日志快速解析，Unicode、光标控制和全屏应用保留 VT 路径。可运行 `node integrations/dsh-remote-ops/test/benchmark-ui.mjs` 比较 v0.4.0；只测解析，不代表 SSH、网络或完整界面耗时。

## 验证与边界

- 自动化门禁、12/12 浏览器场景、真实 DSH 安装及深浅/窄屏界面记录见 [v0.5.0 验收说明](https://github.com/Ssshake1996/myterm/blob/main/docs/testing/dsh-remote-ops-v0.5.0-acceptance.md)。安装包由 CI 完整门禁后生成并附 SHA256。
- 未新增接管/暂停/停止按钮或对应 Agent 工具；停止 Agent 继续使用 DSH 主对话。已发出的网页动作不会回滚；远端命令超时/取消不证明进程退出。
- 运行中任务不跨插件卸载或 DSH 重启恢复。浏览器上传仍不支持整页刷新或进程重启后的断点续传。独立命令正文不跨整页刷新保存。
- SSH 参数空格问题未纳入本次修复。其他 DSH 版本、多机可见浏览器及任意第三方登录网站未作兼容性保证。
