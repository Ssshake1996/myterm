# myterm v0.9.7

## MCP Transport 重构

- 将 MCP 客户端重构为统一 Transport 抽象，Agent 工具循环不再绑定具体传输实现。
- 保留并兼容 `stdio` MCP，新增 `streamable-http` MCP。
- Streamable HTTP 支持 URL、HTTPS/HTTP 校验、自定义请求头和会话重连。
- MCP 连接、工具发现和工具调用共用同一套超时、权限、错误详情和审计路径。
- MCP 设置界面支持按传输类型切换表单，并可测试未保存的 HTTP MCP 草稿。
- 更新系统文档、Agent 能力说明和 MCP 故障排查说明。

## 验证

- 前端测试、Lint、TypeScript 构建通过。
- Rust 格式检查和单线程类型检查通过。
- Release 安装包、便携包和 SHA-256 校验文件由标准脚本生成。
