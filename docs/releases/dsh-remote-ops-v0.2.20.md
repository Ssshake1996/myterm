# dsh-remote-ops v0.2.20

## 改进

1. 连接使用稳定编号和可编辑备注，标签、选择器、快捷命令目标和释放确认显示同一名称；仍限制每个 owner/环境最多 3 条连接，按需创建。
2. SSH 断开后保留标签和末次输出，显式重连，不重放命令、不暗中切换目标；网络轮询失败使用有上限的退避。
3. 显示工具实际返回的时间、输出范围和之后是否有新输出；按 owner/stream 隔离，UI 读取不伪造模型已读回执。
4. SFTP 提供逐项结果、仅重试未完成项、目标目录自动刷新和文件定位；覆盖前展示两端大小及修改时间。
5. SFTP 按 Harness 会话保存两侧位置、路径、排序、滚动和路径书签；初次打开跟随活动环境，不向终端注入 cd。定位文件保留排序，切换端点加载期间禁止编辑旧路径。
6. 浏览器窗口级输入权，显式跨窗口接管；旧窗口只读，不能交还另一窗口的输入权。输入队列和粘贴同时锁定目标与输出流。
7. 修复 top/vim 字符集控制序列残留、备用屏恢复、滚动区域和全屏网格换行问题；光标遵守程序可见性。
8. 新增独立命令面板及 remote_command_execute 工具，通过宿主 subprocess 或已有 SSH exec 通道返回真实退出码、独立 stdout/stderr、耗时和截断信息。支持取消/超时，不污染交互 PTY，不继承其 cd/export。

无新运行时依赖，无旧数据迁移，无第二套 Agent、权限或模型循环。

## 验证

- `npm run check` 通过：50 项后端/传输/路由/独立命令测试、22 项客户端行为、7 项契约及烟测。新增功能与验收发现的缺陷均先补失败回归，再修改实现。
- 本机 DSH 0.1.5-rc.1 的 3080：连接编号/备注、3 连接上限、逐个释放；双浏览器窗口输入互斥与接管；SSH 退出后保留输出并显式重连。
- 真实独立 CMD 返回退出码 7，SSH 返回退出码 9 和中文输出；stdout/stderr 分离，交互 PTY 未收到独立命令。真实模型一次调用新工具，再读 local-cmd：退出码 7、stdout `MODEL020-OK`、stderr `MODEL020-ERR`、durationMs 127。已展开核对工具原始结果，耗时仅是样本，不是性能基准。
- 真实 SFTP 3,145,751 字节上传、同一远端跨目录复制及下载逐字节一致。中途冲突后，重试仅复制剩余 3 项，最终 4 项完成；覆盖预览、自动刷新、定位保留排序、路径/排序/180px 滚动恢复通过。
- 真实 top/vim 进入、退出及 shell 恢复；240 行 CMD 输出、历史阅读位置、末行、复制、快捷命令、SFTP 面板往返，桌面和 390px 窄屏无外层溢出/未捕获页面异常。
- 下载验收曾触发宿主 `MaxListenersExceededWarning: Possible EventEmitter memory leak detected. 11 drain listeners added to [Gzip]`。堆栈定位到 `compression/index.js:148` 和 `dsh-client-connection/lib/index.js:99` 的响应背压桥。插件二进制下载声明 `Cache-Control: no-store, no-transform`，避免额外 HTTP 压缩，不修改宿主或隐藏警告；重启后的大文件重复下载再次核对原始长度、无 Content-Encoding 和字节一致性。

## 边界

- 未验证两台物理客户端差异、操作系统输入法候选提交、两台不同 SSH 服务实际互传；双窗口和模拟 IME 测试不能替代这些验收。
- 当前宿主没有运行时 PTY resize API，保留 160×40 网格；窄面板使用滚动，不声称自动适配 PTY 或完整 xterm 兼容。交互 PTY 仍返回 completion=unknown。
- 独立命令是非交互执行，不能接管已有 shell 状态；远端关闭通道不证明进程已终止，取消/超时如实返回 unknown。每个目标最多一个活动独立命令、总计最多 8 个；默认 30 秒、上限 300 秒，stdout/stderr 分别默认 64 KiB、上限 256 KiB。
- 连接编号/备注和传输任务为进程内状态；文件重试不跨 DSH 重启、不回滚已完成文件，浏览器上传需重新选择文件。目录深度 32/条目 10,000，任务并发 2，排队及运行合计 20。
- 3080 仅用于开发验收，不代表另一台电脑的生产事实。宿主 SQLite ExperimentalWarning 与插件错误分开记录。
