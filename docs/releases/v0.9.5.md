# myterm v0.9.5

发布日期：2026-08-27

## 本版更新

- 增加结构化 SSH 连接诊断：连接失败会保留失败阶段、错误码、概括和原始详情，支持在界面展开查看详细堆栈与请求上下文。
- 增加 `session_catalog` 只读 Agent 工具：Agent 可以检索已保存服务器、当前会话状态和最近一次连接诊断，不读取密码、私钥或 API Key。
- 支持 Agent 通过 `session_id`、`profile_id` 或 `profile_name` 定位非活动 SSH 会话；终端、远程命令、主机事实、目录和文件工具会沿用显式目标。
- 完善目标会话的权限判定，避免因 UI 当前焦点不同而错误放行或阻止工具调用。
- 更新 dsh-codex-agent 系统 Prompt、中文/英文 README、用户说明书和 Linux Agent 规格，明确非活动会话发现与诊断使用方式。
