# myterm v0.13.0

## DeepSeek Harness remote-ops plugin

- Added the standalone `@dsh/remote-ops` plugin for DeepSeek Harness.
- Added owner-scoped SSH terminal sessions backed by `ctx.terminals`.
- Added saved environment groups, quick-command execution, SFTP operations, multi-target sequential batches and diagnostics.
- Added a DSH right Sidebar with environment, terminal, quick-command, SFTP and diagnostics views.
- Removed the old external myterm bridge from the Harness runtime path.
- Added independent plugin smoke checks and runtime profile checks.

The plugin package is shipped separately as `dsh-remote-ops-v0.13.0.tgz` so it can be installed into a DSH profile without installing the myterm desktop application.
