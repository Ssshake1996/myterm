# dsh-remote-ops v0.15.3

环境管理改为插件工作区内的左侧抽屉，顶部工具栏与标签收紧留白，让终端和网页获得更多可用空间。

- 默认使用 360px 浮层；插件面板小于 480px 时占满工作区，达到 960px 时可固定为 320px。收窄自动恢复浮层，并记住固定偏好。
- SSH、Telnet、串口和 API 环境共用抽屉。搜索和分组选择集中显示，行内保留“连接/使用”和“更多”，编辑、测试、删除收进更多菜单。表单保存/取消操作固定在底部。
- 支持关闭按钮、Esc 和点击遮罩；关闭后恢复环境入口焦点。保留普通表单草稿，已查看的密码在关闭后清除。
- 抽屉开关保留终端、网页及 API 面板，不重建连接，不改变浮层背后的网页视口，不停止录制。
- 顶部工具栏约 40px、工作区标签按钮 36px；保留文字、图标、键盘导航和后台状态提示。

已通过 491 项本地检查、6 组真实浏览器回归及 Windows DSH Desktop 0.2.1-rc.5 本机验收。覆盖草稿、焦点、窗口缩放、终端状态、内置浏览器和录制导出。窄屏/暗色及 Agent 并发操作另在真实浏览器测试环境验证；未将其他宿主版本或外部真实设备计入本次验收。

桌面版通过 DSH 插件管理安装附件，按安装器提示允许随包准备脚本。结束正在执行的任务后完整退出并重新打开 DSH，在 Remote Ops 设置中确认“当前运行”和“已安装”均为 **0.15.3**。Web profile 可使用：

```sh
dsh plugin --profile web add ./dsh-remote-ops-v0.15.3.tgz
```

从 v0.14.1 及更早版本升级请使用 DSH 插件管理或 CLI，旧更新器存在 64 MiB 下载限制。本版继续附带 Windows/Linux x64 内置浏览器；Linux 仍需系统动态库。

附件：`dsh-remote-ops-v0.15.3.tgz`、`SHA256SUMS-dsh-remote-ops-v0.15.3.txt`。正式包由发布 CI 重新构建，摘要以发布附件为准。本地 0.15.3 验收包与正式包不保证字节相同，手动安装正式附件可替换同版本验收包。
