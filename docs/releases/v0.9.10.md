# myterm v0.9.10

本版本修正高分辨率字号同步，并把 Agent 的 SSH 使用从手动绑定重构为模型显式选择的动态目标契约。MCP 诊断和结果解析也进入 Agent 可调用、可审计的统一路径。

## 主要变化

- 全局 90%-200% 字号倍率现在同时作用于侧栏、标题、面板、弹窗和 xterm。终端保留 12-22px 基础字号，最终字号按“基础字号 × 界面倍率”计算，调整时不重连会话。
- Agent 面板移除“绑定活动会话”开关，改为展示被动的“活动 SSH 候选”。一般问答、MCP、Skill 与历史任务不会自动读取 SSH；当前终端任务由模型显式设置 `use_active_session=true`，命名服务器任务使用明确 `session_id`。
- 所有会话工具缺少目标时闭合失败，不再静默使用当前焦点。Multi-SSH 继续通过 `session_catalog`、`session_connect` 和逐工具目标选择协同执行。
- 新增只读 `mcp_status`，Agent 可查看所有 MCP 服务器的 Transport、启用/连接/发现状态、工具数量、错误码与服务端原始详情，无需绑定 SSH。
- MCP 调用结果统一提供 `structuredContent`、合并后的 `textContent`、错误/截断状态和 Evidence 引用；长结果可以分页读完后再生成产品 CLI 命令。
- 编辑已保存会话时关闭主机、用户名和密码等字段的浏览器自动填充，减少打开后短暂无法输入的问题。
- 延续此前修复：连接错误保留原始阶段、代码与详情；Profile 编辑测试、MCP 错误链和 Agent 系统 Prompt 均增加回归覆盖。

## 升级说明

Windows 安装器会替换旧版本程序并保留服务器、快捷命令、AI/Agent 配置和系统凭据引用。便携版请解压到新的目录或替换完整目录，不要只复制单个 EXE。

## 验证范围

- 前端单线程测试、Biome lint、TypeScript/Vite 生产构建。
- Rust format、单线程 type check 与 Agent/MCP/会话目标单元测试。
- 150% 浏览器布局和 xterm 字号同步回归。
- NSIS 安装器、便携 ZIP、分发审计、SHA256 与 35 秒运行时内存/句柄采样。

## 当前边界

- Agent 由模型根据对话选择 SSH 目标，不增加前端关键词路由器。含糊目标会要求用户补充，模型漏选目标会得到明确错误。
- 不新增常驻服务、复杂多 Agent、长期记忆或通用任务编排，继续保持轻量桌面内核。
