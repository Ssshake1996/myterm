# dsh-remote-ops v0.2.28

修复浏览器上传在切换终端、SFTP 或离开 Remote Ops 面板时被取消的问题，并消除历史传输和同轮完成任务引发的重复目录刷新。基于已发布的 v0.2.27，保留原生左侧导航、终端输入保护与全部工具边界。

## 交互变化

- 上传批次由插件持有，不再由文件视图的挂载状态控制。切换页面后批次继续，返回可查看文件序号、进度、取消和失败信息；终端页标题提供查看上传进度按钮。
- 每批次固定原 Harness owner、目标目录和冲突策略。覆盖预览在上传前完成；确认时离开不会自动开始上传。取消只影响当前 owner 的批次，中止当前浏览器请求且不再发送剩余文件；不是回滚，服务端已接收的文件可能完成。完成后释放浏览器 File 对象，只保留状态与目录失效所需的任务摘要。
- 整页离开时提示仍有上传，插件卸载会清理监听并中止请求。关闭/刷新整页或停止 DSH 可能中断上传；不提供跨刷新恢复或字节级断点续传，已完成文件保留。
- 首次轮询只记录传输历史。新完成任务按可见面板合并刷新，浏览器完成回执与服务端轮询使用同一任务 ID 去重。正在读取的面板只排一次后续刷新，不并发覆盖目录结果。
- 同目录刷新保留已有列表、有效选中项和用户最新滚动位置；不同目录导航保留原有清理和过期响应丢弃行为。
- 修复窄屏且传输历史较多时文件列表被挤到 14px 的问题：两侧面板保留最小高度，文件区可纵向滚动访问目标 B，不侵入任务区。
- 仓库首页、包内中英 README、安装与发布命令同步 v0.2.28。没有新增运行时依赖或改变服务端传输、工具、存储格式。

## 安装

在启动 DSH 的同一系统用户、`DSH_HOME` 和实际 profile 下安装（以下为 web 示例），然后完全重启 DSH 并刷新浏览器：

```powershell
dsh plugin --profile web add .\dsh-remote-ops-v0.2.28.tgz
dsh web
```

确认标题显示 `v0.2.28`。环境与快捷命令数据保留，已有终端连接需重新打开。DSH `0.2.0-rc.2` 为本轮目标宿主；其他版本需实际验证。

- 发布门禁包含 32 个文件语法检查、129 项后端/发布测试、90 项客户端测试、11 项契约测试和 smoke，共 230 项测试。

## 边界

浏览器上传属于当前浏览器页内的插件生命周期，不是可跨浏览器关闭的服务端持久任务。独立命令的组件卸载策略未修改。真实远端 SSH/SFTP、其他物理电脑、操作系统输入法和模型调用仍需对应环境验收。
