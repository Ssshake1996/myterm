# dsh-remote-ops v0.18.0

嵌入网页默认自动适配面板。宽页面先以至少 1280 CSS 像素打开，再按检测到的页面布局扩宽并等比完整显示当前视口；拖动分栏即可即时调整画面，无需反复设置缩放。

- 记忆同一网站的稳定最低宽度，后续在首次导航前恢复。手动设置的网站宽度继续生效。
- 用户和 Agent 操作时显示短暂位置标示；原始大小模式下，面板滚动到操作目标附近。长页面与内嵌滚动区域保持正常滚动。
- 自动化定位、截图和点击继续使用浏览器 CSS 像素。有效观察及动作期间延后逻辑视口调整，避免侧栏拖动使已取得的截图坐标失效。
- 标示只存在于插件 GUI，不注入网页，不补发点击或滚动，也不增加录制事件。
- 保留原始大小、跟随面板适应两种手动模式。升级时一次性启用新默认，此后用户选择会保存。
- 同步中英文 README、网页使用说明、MCP 坐标约定、浏览器与网页录制随包 skill、回归门禁。

网站若只在启动时检查更高的隐藏断点，仍可保存最低宽度后再打开；插件不会自动刷新未保存表单。自动适配显示的是当前浏览器视口，长页面继续滚动，不能保证把任意整页内容压缩成一屏。

发布资产仅为 `dsh-remote-ops-v0.18.0.tgz` 与 `SHA256SUMS-dsh-remote-ops-v0.18.0.txt`。安装包带匹配的 Windows x64 / Linux x64 内置浏览器运行库；本次不修改 Agent。
