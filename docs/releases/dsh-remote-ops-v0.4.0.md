# dsh-remote-ops v0.4.0

网页模块支持输入网址直接浏览，并让 DSH Agent 操作当前网页。无需先新增网站或编排流程；原生右侧 Sidebar 保留主对话，左侧入口仍与宿主保持左对齐。

- 可配置“插件内”实时交互画面与“独立窗口”。插件内支持点击、滚动、键盘和中文文本输入，页面标签、地址栏、后退/前进/刷新及 Ctrl+Esc 返回地址栏。
- 人与 Agent 共享网页和终端，对话执行期间均可输入。不设接管、交还或输入权限制；网页、终端不保留接管/暂停/停止按钮，也不新增对应 Agent 工具。停止 Agent 使用 DSH 原生停止对话入口。
- 原生对话取消会阻止网页后续步骤；当前动作等待结算，已发出的效果不能撤销。终端正在等待发送时取消会尝试 Ctrl+C，不能据此断言远程进程已退出。页面变化后不重放旧画面的输入。
- 收藏网站、登录配置、XPath/CSS/role/label/text、iframe、弹出网页与参数流程保留在折叠的高级区域。实时画面、操作记录分开更新，模块切换与 DSH 页面刷新保留浏览器和后台任务。
- 显示模式切换保留浏览器 ID、页面 URL 和登录 Cookie，但会重新载入网页，未提交表单不会恢复；运行中或有原生弹窗时不能切换模式。独立窗口要求 DSH 所在主机具备交互桌面。
- 四份中英文 README、网页说明、测试计划和版本载体同步更新。

## 验证与边界

- 自动化覆盖网址直开、实时画面、共享输入、原生取消信号、跨对话隔离、页面失效检查、模式切换、登录 Cookie、iframe/弹窗、去重和既有 SSH/SFTP 回归。
- 完整插件检查通过：157 项后端测试、92 项客户端测试、11 项契约测试及加载 smoke；报告工具 4 项测试通过。真实 Chrome 的 11 个端到端场景全部通过，包含既有终端、SSH 和 SFTP 回归。
- 独立 DSH `0.2.0-rc.2` Web profile 从 tgz 安装验收：版本 `0.4.0`、左侧图标/文字 x=22/46、重复打开复用一个右栏标签、主对话编辑器 DOM 和草稿保留；1280px/390px、标签键盘及显示模式切换通过。390px 无横向溢出。
- 使用仅本机的确定性模型接口驱动真实 DSH Agent 工具链，原生“停止生成”按钮验证通过：网页等待期间可点击/中文输入，停止后任务为 `stopped`、0/2 步、无后续操作；本次约 164ms。终端等待期间人工回显可用，停止后活动为 `cancelled`，本次约 55ms。耗时是本机观测值，不是性能承诺；这不是外部模型或业务网站验收。
- 本地测试站点通过不代表任意业务网站兼容。验证码/MFA 需用户完成；未提供任意 JavaScript、文件选择器/网页文件传输、录制器、拖拽、剪贴板复制、音视频流或跨电脑可见浏览器。
