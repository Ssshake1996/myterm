# myterm v0.9.13

本版本重构 SSH 终端显示区域的尺寸与滚动约束，修复高分辨率和 150% 界面缩放下底部内容、光标行被裁切的问题。

## 主要变化

- 修复终端 host 在界面缩放下被错误放大的问题，终端现在严格受工作区和分屏容器约束。
- 修复快捷命令面板覆盖终端底部内容的情况，最后一行和当前光标行可以正常显示。
- Agent 输出、用户输入和终端解析完成后保持底部可见，用户滚动离开底部时提供“↓ 底部”快捷按钮。
- 自动换行关闭时强制保留可见的横向滚动区域，并在切换模式后重新适配终端尺寸。
- 为工作区、终端区、快捷命令区和 AI 面板增加分层背景、内阴影和独立分隔线，提升模块边界辨识度。

## 验证范围

- 本地浏览器在 1280×720、150% 界面缩放下完成终端布局实测。
- 自动换行模式切换后，横向滚动条实际占用终端视口高度。
- `npm test`：59 项通过。
- `npm run lint`、`npm run build` 和 `git diff --check` 通过。
