# dsh-remote-ops v0.15.3 验收记录

本版交付环境抽屉和顶部空间优化。详细本机操作证据见 [2026-11-10 本地验收](environment-drawer-local-acceptance-20261110.md)。

| 验收层 | 内容 |
| --- | --- |
| 本地检查 | 338 单元、130 客户端、12 契约、11 桌面测试，另含语法、生成代码同步、smoke 和 DSH UI 契约检查。 |
| 真实浏览器回归 | 环境抽屉、环境分组及批量管理、密码遮蔽与关闭清理、终端标签、工作区状态保持、API 请求，共 6 组通过。 |
| 状态与布局 | 390px/570px/宽屏、暗色、固定后收窄、Esc 和焦点恢复、草稿保留、终端 DOM 及浏览器会话保留；抽屉打开期间 Agent 操作仍能录制和导出。 |
| 本机 DSH | Windows DSH Desktop 0.2.1-rc.5；通过插件管理安装并完整重启，本地验收包运行/安装版本均为 0.15.3。浮层、全屏固定、恢复浮层和 SSH/API 草稿检查通过。 |
| 内置浏览器与录制 | 无额外浏览器下载，使用本地页面；抽屉开关前后保存次数连续从 1 到 2。UI 导出 25 个事件，同一 browser/page，包含前后标记，不含抽屉搜索输入，无未完成动作。 |
| 正式包发布门禁 | Windows 原生桌面、Linux 打包、原生 DSH 串口与随包浏览器录制由 GitHub Actions 对发布 tag 执行，全部通过才公开发布附件。 |

浏览器报告位于 `output/e2e/environment-drawer-3/`、`drawer-terminal-tabs/`、`drawer-layout/`、`drawer-api/`，本机证据位于 `output/local-drawer/`。这些本地证据目录不包含在发布包中；CI 证据保存在对应 Actions 运行的附件里。

本机 UI 使用人工操作；Agent 并发验证在真实浏览器测试环境进行。本机验收未访问外部设备，也不覆盖所有 DSH 版本或平台。正式 CI 包重新构建，需核对正式附件与 SHA256，不能用本地验收包摘要替代。
