# Remote Ops v0.15.12 SSH 私钥口令验收

2026-11-17 在 Windows 的独立 DSH 0.2.1-rc.5 Web 配置安装 v0.15.12 候选包，使用 Chrome 操作插件表单。两个本机 SSH 服务分别只接受指定的 Ed25519 公钥，并校验客户端签名。DSH 工具调用使用隔离的模型夹具。8 项宿主验收通过，宿主页面未记录 JavaScript 错误。

| 场景 | 实测结果 |
| --- | --- |
| 未加密私钥 | Agent 仅设置私钥路径，打开终端并执行 `show version`，收到设备回显。服务端成功校验 1 次签名。 |
| 加密私钥 | 在真实表单中输入含中文及首尾空格的口令，编辑时留空并保存。环境测试通过认证、PTY、SFTP 和远端目录解析，终端可执行命令。 |
| 保存与重启 | 重启隔离 DSH 后，原环境使用已保存口令再次连接。加密私钥在整个验收中完成 4 次签名认证。 |
| 错误、清除、补录 | 输入错误口令返回 `SSH_KEY_PASSPHRASE_INVALID`。显式清除返回 `SSH_KEY_PASSPHRASE_REQUIRED`。这两次操作均在本地解析私钥阶段结束，服务端连接计数没有增加。即使账号密码与正确口令相同，也需在私钥口令字段补录后才能重连。 |
| 凭据与回归 | 同轮验证 SSH/Telnet 账号密码和 API Token/Cookie 登录。单元测试覆盖更新留空、并发修改、删除，以及环境文件写入失败时恢复原凭据。环境 JSON、工具结果和诊断摘要均有明文排除检查。 |

本地回归通过 349 项单元、131 项客户端、12 项契约、11 项桌面测试及插件 smoke。Chrome 工作区端到端场景通过 25/25。核对安装后的连接层、客户端、两份 README 和随包环境管理及 Windows skill，均与源文件一致。
