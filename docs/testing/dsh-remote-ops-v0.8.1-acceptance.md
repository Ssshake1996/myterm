## 发布边界

发布附件仅为 tgz 和 SHA256；`latest.json` 由随包脚本在部署更新源时生成。正式附件下载、摘要比对与安装复验在发布后另行记录。

已验证实际 Windows 文件目录、HTTP 和 SFTP，未连接用户内网或真实企业 UNC 共享盘，也未验证企业私有 CA、依赖镜像及域账号权限。依赖下载沿用 DSH 原有配置，不把更新目录当作 npm 源。安装保留连接不代表重启保留任务；完全重启 DSH 并刷新浏览器后才确认新版后端与 skill 生效。
