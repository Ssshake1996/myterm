# 01 产品规格(MVP)

## 一句话定义

**myterm** 是一个轻量级桌面 SSH 客户端(对标 Xshell + MobaXterm 的核心体验):流畅的 SSH 终端、同连接 SFTP 文件传输、本地终端,并且**原生内置 AI 助手**(任意 OpenAI 兼容服务),开箱即可对终端上下文提问、解释报错、生成命令。

## 目标用户与场景

运维工程师 / 后端开发者,日常工作是连接多台 Linux 服务器执行命令、传输文件。他们:

- 现在用 Xshell + Xftp(要开两个程序)或 MobaXterm(功能全但笨重),都没有 AI 能力;
- 在意软件的轻量程度(常年开着几十个会话,不接受 Electron 级别的内存占用);
- 遇到报错时习惯把终端输出复制到 AI 对话框里问——myterm 把这一步做成原生体验:一键抓屏提问、命令一键回填。

## MVP 用户故事(全部必须满足)

| # | 故事 | 验收标准 |
|---|---|---|
| U1 | 我可以创建并保存会话配置(主机、端口、用户名、认证方式) | 支持密码和私钥(含 passphrase)两种认证;配置持久化,重启后仍在 |
| U2 | 我双击会话即连接,进入可交互的终端 | `vim`、`top`、`htop` 渲染正常;UTF-8 中文不乱码;窗口 resize 后远端同步;复制粘贴、滚动回看、搜索可用 |
| U3 | 我可以同时开多个会话,以标签页 + 左右分屏组织 | 标签可拖拽排序;分屏各自独立会话;关闭标签正确断开连接 |
| U4 | 我的密码/私钥 passphrase 加密保存,不落明文 | 凭据存入操作系统凭据管理器(Windows 凭据管理器 / macOS Keychain / libsecret);配置文件中只有引用,无明文 |
| U5 | 我在终端标签内一键切出 SFTP 面板,浏览和传输文件 | 复用当前 SSH 连接免二次登录;本地/远程双栏;上传下载有进度和速度;支持拖拽和多文件队列 |
| U6 | 我可以配置任意 OpenAI 兼容的 AI 服务 | 服务商预设(OpenAI/DeepSeek/Ollama/自定义网关)+ Base URL / API Key / 模型 / System Prompt;「测试连接」能验证;Key 存 OS 凭据库,配置文件无明文;支持多配置档切换 |
| U7 | 我随时唤起 AI 对终端内容提问,回答中的命令一键回填 | 右侧 AI 面板常驻可折叠;Ctrl+Shift+A 抓取活动终端最近 N 行提问;回答流式显示;代码块带「复制」「回填终端」(回填**不自动回车**);新提问自动中断上一个未完成回答 |
| U8 | 我可以维护快捷命令集,点一下就把常用命令发到当前终端(对标 Xshell 快捷命令) | 底部快捷命令栏,按分组切换命令集;点击按钮把命令发送到活动终端,每条命令可配置是否自动回车;右键新增/编辑/删除/排序;数据持久化 |
| U9 | 我可以打开本地终端(PowerShell / WSL) | 本地终端与 SSH 会话同样以标签管理;AI 面板与快捷命令对本地终端同样可用 |
| U10 | 我拿到的是标准 Windows 桌面程序 | 提供 NSIS 安装包和绿色便携版;双击即用,不依赖已装浏览器/运行时 |

## 非功能要求(硬指标)

- **资源**:1 个空闲 SSH 会话的整机内存占用 < 80MB;安装包 < 20MB。
- **性能**:`cat` 一个 10MB 文本文件不卡死 UI,吞吐 ≥ 5MB/s;按键回显延迟无肉眼可感知的额外延迟;AI 流式回答首 token 显示延迟只受服务端限制。
- **安全**:凭据与 AI Key 只经 OS 级加密存储;AI 请求只发往用户配置的 Base URL,抓屏内容发送前在面板中可见(用户知道发出了什么);任何日志/错误消息不得包含 Key 或密码。
- **健壮**:网络断开时会话标签显示断开状态并可一键重连;AI 请求失败(超时/限流/断网)给出可读错误且可重试;SFTP 传输失败可重试单个任务。
- **可观测**:`--debug` 启动时,内核日志写入 `%APPDATA%/myterm/logs/`(AI 请求只记元数据:配置档、模型、token 量级,不记内容)。

## MVP 功能边界

### 做

- SSH-2 连接:密码认证、公钥认证(OpenSSH 格式私钥,含 passphrase)、keyboard-interactive 的简单透传
- 终端仿真:xterm-256color,由 xterm.js 承担(WebGL 渲染)
- SFTP:目录浏览、上传/下载(含目录递归)、重命名、删除、新建目录、权限查看
- 本地终端:PowerShell / cmd / WSL(检测可用 shell 列表)
- 会话管理:分组树、搜索、最近连接
- **快捷命令**:分组命令集、底部命令栏一键发送(每条可配自动回车)、增删改与排序
- **内置 AI**:多配置档的 OpenAI 兼容客户端(Rust 侧、SSE 流式)、常驻 AI 面板、抓屏提问、命令回填、多轮对话(会话内存级,不持久化)
- Windows 分发:NSIS 安装包 + 便携版;macOS/Linux 构建保持可编译但不做发布打磨

### 明确不做(P2 或更晚)

- ❌ **插件体系**(P2:插件宿主、权限模型、SDK——契约见 `04-plugin-system-p2.md`,实施后置)
- ❌ AI Agent 自动执行命令、多步任务编排(回填永远不带回车)
- ❌ AI 对话历史持久化、知识库/RAG
- ❌ 串口 / Telnet / Rlogin / Mosh / RDP / VNC / X Server(MobaXterm 的重功能不跟)
- ❌ 端口转发的图形化管理
- ❌ 脚本录制回放、按键宏、ZMODEM(rz/sz)
- ❌ 会话云同步、团队共享、Web 版 / 移动版
- ❌ 跳板机多级代理(MVP 只做直连)

## 命令行接口

```
myterm                       # 正常启动
myterm --debug               # 输出调试日志到 %APPDATA%/myterm/logs/
myterm --profile <name>      # 启动后直接连接指定会话配置
myterm --portable            # 便携模式:配置读写 .exe 同目录的 data/ 而非 %APPDATA%
```

| 本地终端 | ❌ | ✅ | ✅ |
| 快捷命令集 | ✅ | 部分(宏) | ✅ |
| AI 助手 | ❌ | ❌ | ✅ 原生内置 |
| 扩展体系 | ❌ | ❌ | P2(插件) |
