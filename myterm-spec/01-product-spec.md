# 01 产品规格(MVP)

## 一句话定义

**myterm** 是一个轻量级桌面 SSH 客户端:提供流畅的 SSH 终端和 SFTP 双栏文件传输,通过类 VSCode 的插件体系扩展一切附加能力(首个官方插件为 AI 助手)。

## 目标用户与场景

运维工程师 / 后端开发者,日常工作是连接多台 Linux 服务器执行命令、传输文件。他们:

- 现在用 Xshell + Xftp,但要开两个程序、且没有任何 AI/自动化扩展能力;
- 在意软件的轻量程度(常年开着几十个会话,不接受 Electron 级别的内存占用);
- 希望像 VSCode 一样通过装插件按需增强(AI 问答、主题、命令片段)。

## MVP 用户故事(全部必须满足)

| # | 故事 | 验收标准 |
|---|---|---|
| U1 | 我可以创建并保存会话配置(主机、端口、用户名、认证方式) | 支持密码和私钥(含 passphrase)两种认证;配置持久化,重启后仍在 |
| U2 | 我双击会话即连接,进入可交互的终端 | `vim`、`top`、`htop` 渲染正常;UTF-8 中文不乱码;窗口 resize 后远端同步;复制粘贴、滚动回看、搜索可用 |
| U3 | 我可以同时开多个会话,以标签页 + 左右分屏组织 | 标签可拖拽排序;分屏各自独立会话;关闭标签正确断开连接 |
| U4 | 我的密码/私钥 passphrase 加密保存,不落明文 | 凭据存入操作系统凭据管理器(Windows 凭据管理器 / macOS Keychain / libsecret);配置文件中只有引用,无明文 |
| U5 | 我在终端标签内一键切出 SFTP 面板,浏览和传输文件 | 复用当前 SSH 连接免二次登录;本地/远程双栏;上传下载有进度和速度;支持拖拽和多文件队列 |
| U6 | 我可以从本地目录安装插件,安装时看到它申请的权限 | 安装时展示 `permissions` 清单待用户同意;插件按 `activationEvents` 懒加载;插件崩溃不影响终端 |
| U7 | 插件能注册命令、侧边栏面板,能读终端屏幕、写入命令 | 用内置插件验证:主题插件(注册配置项+换配色)、命令片段插件(侧边栏面板+点击回填命令) |
| U8 | 我安装 AI 助手插件后,可配置任意 OpenAI 兼容服务并对终端内容提问 | 可配 Base URL / API Key / 模型;"测试连接"能验证;抓取终端最近输出提问,回答流式显示;回答中的命令一键回填到终端(不自动回车) |
| U9 | 我拿到的是标准 Windows 桌面程序 | 提供 NSIS 安装包和绿色便携版单 .exe;双击即用,不依赖已装浏览器/运行时 |

## 非功能要求(硬指标)

- **资源**:零插件时,1 个空闲 SSH 会话的整机内存占用 < 80MB;安装包 < 25MB(不含插件宿主的 Node 运行时时 < 15MB)。
- **性能**:`cat` 一个 10MB 文本文件不卡死 UI,吞吐 ≥ 5MB/s;按键回显延迟无肉眼可感知的额外延迟。
- **安全**:凭据只经 OS 级加密存储;插件的每一次敏感调用(读屏、写终端、读密钥、网络)都经 Rust 内核的 PermissionBroker 裁决;未声明或未授权的权限一律拒绝。
- **健壮**:网络断开时会话标签显示断开状态并可一键重连;插件宿主崩溃自动重启且终端不受影响;SFTP 传输失败可重试单个任务。
- **可观测**:`--debug` 启动时,内核和插件宿主的日志写入 `%APPDATA%/myterm/logs/`。

## MVP 功能边界

### 做

- SSH-2 连接:密码认证、公钥认证(OpenSSH 格式私钥,含 passphrase)、keyboard-interactive 的简单透传
- 终端仿真:xterm-256color,由 xterm.js 承担(WebGL 渲染)
- SFTP:目录浏览、上传/下载(含目录递归)、重命名、删除、新建目录、权限查看
- 会话管理:分组树、搜索、最近连接
- 插件系统:本地目录安装、manifest(contributes / activationEvents / permissions)、命令面板、侧边栏 Webview、状态栏项、配置项、快捷键
- 两个内置插件(主题、命令片段)+ 一个官方插件(AI 助手)
- Windows 分发:NSIS 安装包 + 便携版;macOS/Linux 构建保持可编译但不做发布打磨

### 明确不做(MVP 之后再说)

- ❌ 串口 / Telnet / Rlogin / Mosh
- ❌ 端口转发的图形化管理(命令行 `-L/-R` 等价功能不做 UI)
- ❌ 脚本录制回放、按键宏
- ❌ ZMODEM(rz/sz)
- ❌ 插件市场 / 在线安装 / 插件签名(MVP 只支持本地目录安装)
- ❌ 会话云同步、团队共享
- ❌ Web 版 / 移动版
- ❌ 跳板机多级代理(MVP 只做直连;ProxyJump 之后再说)
- ❌ X11 转发、agent forwarding

## 命令行接口

```
myterm                       # 正常启动
myterm --debug               # 输出调试日志到 %APPDATA%/myterm/logs/
myterm --profile <name>      # 启动后直接连接指定会话配置
myterm --portable            # 便携模式:配置读写 .exe 同目录的 data/ 而非 %APPDATA%
```

## 竞品对照(定位校准)

| | Xshell + Xftp | Tabby | **myterm** |
|---|---|---|---|
| 内存(1 会话) | ~60MB×2 | ~300MB | 目标 < 80MB |
| SSH+SFTP 同连接 | ❌ 两个程序 | 部分 | ✅ 同标签切换 |
| 插件体系 | ❌ | ✅ 无权限模型 | ✅ 含权限模型 |
| AI 助手 | ❌ | 第三方 | ✅ 官方插件 |
