# myterm 界面原型(静态可点击)

浏览器直接打开 `index.html` 即可,无需构建、无任何依赖。本原型只演示交互与布局,所有数据为假数据;对应的产品/架构定义见 `../myterm-spec/`。

## 已覆盖的交互

| 区域 | 可操作 |
|---|---|
| 标签页 | 点击切换会话(SSH ×2 + 本地 PowerShell),状态圆点 |
| 会话树 | 分组展示、搜索过滤、点击连接(新开标签) |
| 终端视图 | 预置输出(nginx 失败场景),命令回填与假执行 |
| 终端/文件切换 | 右上分段按钮或左侧活动栏「文件」图标 |
| SFTP 视图 | 双栏文件列表、「→」上传按钮演示进度/速度、传输队列 |
| **快捷命令栏** | 命令集分组切换(常用/部署/排查)、点击发送(区分自动回车与仅回填)、「＋」新增命令弹窗、折叠 |
| AI 面板 | 输入提问 → 假流式回答;回答含代码块(复制 / ▶ 回填终端);「附带终端上下文」开关(用户消息里可见附带内容);Ctrl+Shift+A 抓屏提问 |
| AI 设置 | 齿轮打开弹窗:服务商预设(OpenAI/DeepSeek/Ollama/自定义网关)、Base URL / API Key / 模型 / System Prompt / 上下文行数、测试连接 |

## 与正式版的对应关系

- 布局即 `02-architecture.md` 目录结构中 `src/components/` 的组件划分(terminal / tabs / quickbar / sftp / sessions / ai / shell);
- 快捷命令按钮的「自动回车 / 仅回填」对应 `QuickCommand.send_newline`;
- AI 面板的行为对应 IPC 契约中的 `aiChat`(流式)、`aiAbort`(停止按钮)、抓屏上下文注入。
